# output-skill-map.txt — maps output file paths to the SKILLs that produced them.
#
# Used by hooks/tap.sh PostToolUse(Write|Edit) branch to detect cached SKILL
# applications — cases where Claude applied a SKILL without re-Reading the
# SKILL.md in this session.
#
# Format: PATTERN | SKILL_NAME
# - PATTERN: shell glob pattern, matched against the absolute output path
# - SKILL_NAME: the SKILL whose application produced this artifact
#
# Lines starting with # are comments. Blank lines ignored.
# Order matters — first match wins. Put more specific patterns first.
